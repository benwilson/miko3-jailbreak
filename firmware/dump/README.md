# Dump #1 — original pre-modification state

First full dump of the Miko 3, taken **before** any partition writes.
The boot chain here is byte-identical to dump #2
(`firmware/dump-parental-locked/`) — nothing in it was ever flashed.

- Captured: 2026-09-11 (factory mode, root ADB)
- Scope: critical partitions only (no userdata/cache/metadata/etc.)
- Companion: dump #2 is the complete 34-image, 29 GB snapshot of the
  restored working state.
